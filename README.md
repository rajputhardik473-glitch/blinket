# 🛒 Blinkit Clone

A simple and modern **Blinkit-inspired grocery shopping website** built using **HTML and CSS**. This project is created for frontend web development practice.

## 🌐 Live Website

🔗 **[Visit Live Website](https://sensational-mandazi-45b47a.netlify.app/)**

## ✨ Features

* 🏠 Modern grocery shopping homepage
* 📍 Delivery location section
* 🔎 Search items bar
* 👤 Login button
* 🛒 My Cart button
* 🖼️ Hero promotional banner
* 🎯 Promotional banners
* 🗂️ Grocery categories
* 🥛 Product cards
* 💰 Product price display
* ➕ Add to cart button
* 🔗 Footer with useful links
* 📱 Font Awesome icons

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **Font Awesome**
* External image assets

## 🧩 Main Sections

### 🔝 Navigation Bar

The navigation bar contains:

* Blinkit logo
* Delivery time
* Location
* Search bar
* Login button
* My Cart button

The project uses Font Awesome icons for the location and cart. 

### 🖼️ Hero Section

A large promotional hero banner is displayed on the homepage. 

### 🎯 Promotional Banners

The website contains multiple promotional banners for different categories such as pharmacy, pets and baby products. 

### 🗂️ Categories

Multiple category images are displayed for browsing different grocery sections. 

### 🛍️ Products

The product section contains product cards with:

* Product image
* Product name
* Quantity
* Price
* ADD button

Example products include Amul Masti Cup Curd, Amul Cheese Cube, Amul Salted Butter and Amul Cheese Block.
